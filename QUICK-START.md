I quick start di STGraphX sono separati in due file:

- `QUICK-START-DEVELOPERS.md`
- `QUICK-START-USERS.md`

## Quale leggere

Leggi `QUICK-START-DEVELOPERS.md` se ti interessa:

- sviluppare STGraphX;
- avviare le shell di sviluppo;
- costruire i bundle;
- generare i pacchetti da distribuire;
- capire cosa distribuire per editor, player e API JavaScript.

Leggi `QUICK-START-USERS.md` se ti interessa:

- usare STGraphX come editor;
- usare il player in una pagina web;
- usare STGraphX da script JavaScript o Node.js.
